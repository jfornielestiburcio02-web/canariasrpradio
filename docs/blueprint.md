# **App Name**: Cadiz Roleplay

## Core Features:

- Discord Authentication: Enable users to securely log in and out of the application using their Discord accounts.
- User Dashboard (Tablonera): Provide a personalized 'Tablonera' dashboard displaying basic Discord user information (e.g., username, avatar) after successful login.
- AI Roleplay Story Hook Tool: Offer a generative AI tool to suggest creative story hooks or character concepts relevant to the 'Cadiz Roleplay' theme.
- Spanish Language UI: Ensure all user-facing interface elements and messages are presented in Spanish.
- Secure Session Management: Maintain authenticated user sessions after Discord login to provide a seamless user experience.
- OAuth Redirect Handling: Correctly handle the Discord OAuth callback and redirect users to the '/tablonera/' path upon successful authentication.

## Style Guidelines:

- The chosen palette reflects the historic and maritime character of Cadiz, combined with an imaginative flair. The scheme is light. Primary color (for interactive elements and headings): A deep, muted sea-blue-grey, evoking ancient stone and calm waters (#3C5567).
- Background color: A very light, almost off-white with a subtle blue tint, providing a clean and airy canvas (#F4F6F7).
- Accent color (for highlights and calls to action): A vibrant aquamarine, reminiscent of bright coastal waters, creating visual interest and contrast (#4EC6CC). This hue is analogous to the primary and distinctly brighter.
- Headline font: 'Alegreya' (serif), chosen for its elegant and intellectual feel, fitting for narrative-driven roleplay. Body text font: 'PT Sans' (humanist sans-serif), offering readability with a modern and warm touch.
- Use a cohesive set of clean, modern icons that are easily recognizable and subtly themed for roleplay elements, without being overly decorative. Leverage Discord's branding for login buttons.
- Employ a clean, spacious layout with a strong emphasis on content readability and a clear call-to-action for Discord login. The dashboard will follow a structured grid for information display.
- Incorporate subtle and smooth transitions for navigation, form submissions, and UI state changes to enhance user interaction without distraction.
